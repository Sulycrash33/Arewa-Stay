# Arewa Stay — Photography Brief

This is the target spec for replacing placeholder/stock imagery once real
photography (host-submitted or commissioned) is available. Current state
uses free-license Pexels stock as a placeholder — functional, but generic
where a specific landmark or interior isn't available.

## Style direction (applies everywhere)
- Real photography or photorealistic AI — no illustration/gradient treatments
- Bright daylight, high resolution, warm inviting color grading
- Consistent editing/color grade across the whole set (same warmth, same contrast curve)
- No repeated images across different cards

## Hero
Target: a real luxury riad / heritage boutique hotel exterior — pool, warm
evening lighting, Sahel-style arches — communicating "premium hospitality"
immediately, not just "a mud house."
Current: Pexels photo of Gidan Dan Hausa (real but modest, not "luxury").

## Property Listings (per-listing gallery, once hosts upload)
Each listing needs a real gallery, not one photo: exterior, living room,
bedroom, bathroom, kitchen, balcony/courtyard — this is what actually gets a
booking, since guests book the property, not the city. This depends on host
photo upload, which is a build item for the listing-creation wizard.
